쿠팡 주문 가져오기

쿠팡 주문목록 화면에서 북마크 하나만 누르면 새 주문이 이 앱에 저장됩니다. 이미 들어온 주문은 자동으로 걸러지니 아무 때나 눌러도 됩니다.

아이폰 설치 방법

  1. 위 북마클릿 코드 복사 를 누릅니다
  2. 사파리에서 아무 페이지나 열고 공유 → 북마크 추가 → 이름을 쿠팡 가져오기 로 저장
  3. 북마크 → 편집 에서 방금 만든 항목을 누르고, 주소칸을 지운 뒤 복사한 코드를 붙여넣기
  4. 쿠팡 주문목록을 열고 주소창 → 북마크 → 쿠팡 가져오기 를 누르면 끝

안드로이드 · PC

PC 크롬 — 북마크바에서 우클릭 → 페이지 추가 → URL 칸에 코드 붙여넣기
안드로이드 크롬 — 북마크 추가 후 편집해서 URL을 코드로 교체
여러 해치 주문을 한꺼번에 모으려면 PC용 크롬 확장을 쓰세요.
