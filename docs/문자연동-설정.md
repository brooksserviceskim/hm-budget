# 문자(SMS) → 생활비 자동 반영 (갤럭시)

카드 승인 문자가 오면 폰이 문자 원문을 서버로 보내고, **서버가 금액·가맹점을 뽑아 지출로 등록**합니다.
폰에서는 설정 두 개만 하면 됩니다. 정규식을 다룰 필요 없습니다.

- 취소 문자, 해외 결제(USD)는 서버가 알아서 걸러냅니다
- 같은 결제는 두 번 등록되지 않습니다
- 카드번호·누적금액은 저장하지 않습니다

---

## 1단계 · Supabase (PC에서, 1회)

SQL Editor 에서 `supabase/migration-sms-raw.sql` 실행.
맨 아래 테스트 문장의 `내가정한비밀문자열` 을 본인 비밀키로 바꿔서 실행하면
`{"ok":true, "amount":64340, "merchant":"쿠팡(쿠페이)"}` 같은 결과가 나옵니다. 그러면 성공입니다.

비밀키를 아직 안 정했다면 먼저 이걸 실행하세요.

```sql
update public.settings
set value = '{"secret":"내가정한비밀문자열"}'::jsonb
where key = 'sms_secret';
```

---

## 2단계 · MacroDroid 설치 (폰)

1. Play 스토어 → **MacroDroid** 검색 → 설치 (제작사 ArloSoft, 무료)
2. 앱 실행 → 안내 화면 넘기기
3. 권한 요청이 뜨면 전부 **허용** (특히 **SMS 읽기**)

---

## 3단계 · 매크로 만들기

홈 화면 아래 **매크로 추가(+)** → 이름 `카드문자 → 가계부`

### ① 트리거 추가
**트리거 +** → **기기 이벤트** → **SMS 수신**

- 발신자 : **모든 번호** (비워두기)
- 내용 : **포함** → `승인`

### ② 액션 추가
**액션 +** → **연결** → **HTTP 요청**

| 항목 | 입력값 |
|---|---|
| 방식 | **POST** |
| URL | `https://jjlmmebptyefmrqbrisw.supabase.co/rest/v1/rpc/ingest_sms_raw` |
| Content Type | `application/json` |

**헤더 추가 (Add header)**

| 이름 | 값 |
|---|---|
| `apikey` | `sb_publishable_WUTZ8a4bBrGALf6WLISXBA_vgzAzi4L` |

**본문 (Body)** — `내가정한비밀문자열` 만 본인 것으로 바꾸세요

```json
{"p_secret":"내가정한비밀문자열","p_raw":"[sms_message]","p_owner":"김현우"}
```

> `[sms_message]` 는 MacroDroid 가 문자 원문으로 바꿔주는 변수입니다.
> 직접 타이핑하지 말고 입력창 옆 **{ } 버튼 → SMS → 메시지 내용** 으로 넣으세요.

### ③ 저장
오른쪽 위 **✓** → 이름 확인 → 저장. 매크로 목록에서 스위치가 **켜짐**인지 확인하세요.

---

## 4단계 · 테스트

카드를 한 번 긁거나, 다음 결제 문자가 올 때까지 기다립니다.
앱 **생활비** 탭을 새로고침하면 `문자` 태그가 붙은 지출이 올라옵니다.

바로 확인하고 싶으면 Supabase SQL Editor 에서:

```sql
select tx_date, merchant, amount, memo
from public.transactions
where source = 'sms'
order by created_at desc limit 10;
```

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 올라옴 | 비밀키가 SQL 과 본문에서 같은지 · `apikey` 헤더 넣었는지 |
| MacroDroid 가 안 돌아감 | 배터리 최적화에서 MacroDroid **제외** (설정 → 배터리 → 앱별 관리) |
| 문자는 오는데 등록 안 됨 | 문자에 `승인` 이 없는 형식일 수 있음 → 그 문자를 알려주세요 |
| 금액이 이상함 | 카드사 문자 형식이 다름 → 그 문자를 알려주세요 |

MacroDroid 무료 버전은 매크로 5개까지 만들 수 있습니다. 이건 1개만 쓰므로 충분합니다.
