# 문자(SMS) → 생활비 자동 반영 설정 (갤럭시)

카드 승인 문자가 오면 **폰이 자동으로 앱에 지출을 등록**합니다.
문자는 폰 안에서만 처리되고, 서버로는 **금액·가맹점·카드명**만 전송됩니다.
카드번호·잔액·누적금액은 보내지 않습니다. 같은 결제는 두 번 등록되지 않습니다.

**원화(₩) 승인 문자만 처리합니다.** 삼성카드 해외승인(`USD 44.58`)은 원화 금액을 알 수 없고,
대부분 AI 구독(사업·투자)이라 생활비 예산 대상이 아니므로 제외합니다.

---

## 0. PC에서 먼저 (1회)

Supabase SQL Editor 에서 `supabase/migration-budget-sms.sql` 실행 후,
비밀키를 본인만 아는 값으로 바꿉니다.

```sql
update public.settings
set value = '{"secret":"내가정한비밀문자열"}'::jsonb
where key = 'sms_secret';
```

---

## 1. MacroDroid 설치

Play 스토어 → **MacroDroid** (무료). 설치 후 문자 읽기 권한을 허용합니다.

---

## 2. 매크로 만들기

**매크로 추가** → 이름 `카드문자 → 가계부`

### 트리거
**기기 이벤트 → SMS 수신**
- 발신자 : 비워두기 (모든 번호)
- 내용 포함 : `승인`

### 조건 (제약)
1. **문자 내용에 `원` 포함** — 원화 결제만
2. **문자 내용에 `취소` 미포함**
3. **문자 내용에 `USD` 미포함** — 해외 결제 제외

### 액션 1 · 금액 뽑기
**변수 → 변수 설정** → 이름 `amount` (정수)
값을 **정규식 추출**으로 지정하고, 대상 `[sms_message]`, 패턴:

```
(?<!누적)([0-9,]+)원
```

→ 캡처 그룹 **1**
`누적64,340원` 은 걸러지고 `64,340원` 만 잡힙니다.

**변수 → 문자열 조작 → 바꾸기** 로 `,` 를 빈칸으로 치환해 숫자만 남깁니다.

### 액션 2 · 가맹점 뽑기
**변수 → 변수 설정** → 이름 `merchant` (문자열)
대상 `[sms_message]`, 패턴:

```
\d{2}/\d{2}\s+\d{2}:\d{2}\s*\n?\s*([^\n]+)
```

→ 캡처 그룹 **1**

- KB국민카드 : `08/01 23:54` 다음 줄 → `쿠팡(쿠페이)`
- 삼성카드 국내 : `07/28 14:23 쿠팡` 같은 줄 → `쿠팡`

### 액션 3 · 카드 구분 (선택)
**변수 설정** → 이름 `card` (문자열)
- 문자에 `KB국민` 포함 → `KB국민카드`
- 아니면 → `삼성카드`

(MacroDroid 의 `조건 분기(IF)` 액션을 쓰거나, 그냥 비워도 됩니다)

### 액션 4 · 서버로 전송
**연결 → HTTP 요청**

| 항목 | 값 |
|---|---|
| 방식 | **POST** |
| URL | `https://jjlmmebptyefmrqbrisw.supabase.co/rest/v1/rpc/ingest_sms` |
| Content-Type | `application/json` |

**헤더**
```
apikey: sb_publishable_WUTZ8a4bBrGALf6WLISXBA_vgzAzi4L
```

**본문**
```json
{
  "p_secret": "내가정한비밀문자열",
  "p_amount": [lv=amount],
  "p_merchant": "[lv=merchant]",
  "p_owner": "김현우",
  "p_card": "[lv=card]"
}
```

### 액션 5 · 확인 알림 (선택)
**알림 → 알림 표시** : `가계부 등록 [lv=merchant] [lv=amount]원`

---

## 3. 테스트

1. 매크로를 저장하고 상단 스위치를 켭니다
2. 실제로 카드를 한 번 긁거나, MacroDroid 의 **테스트 실행** 사용
3. 앱 **생활비** 탭을 새로고침 → 방금 결제가 `문자` 태그와 함께 올라옵니다
4. 분류가 `미분류` 로 뜨면, 앱을 열 때 가맹점 이름으로 자동 분류됩니다

---

## 4. 확인된 문자 형식

**KB국민카드 (쿠팡 와우 카드)**
```
[Web발신]
KB국민카드0952승인
김*우님
64,340원 일시불
08/01 23:54
쿠팡(쿠페이)
누적64,340원
```
→ 금액 `64340` · 가맹점 `쿠팡(쿠페이)` → 앱에서 **쿠팡 / 식료품·비주류음료** 로 자동 분류

**삼성카드 해외승인** — 처리하지 않음
```
삼성2695해외승인 김*우
USD 44.58
07/27 14:43 ANTHROPIC
```

---

## 5. 안 될 때

| 증상 | 원인 |
|---|---|
| 아무것도 안 올라옴 | 비밀키 불일치 · `apikey` 헤더 누락 |
| 금액이 누적금액으로 들어감 | 정규식에서 `(?<!누적)` 빠짐 |
| 가맹점이 비어 있음 | 문자 형식이 다름 → 해당 문자를 알려주세요 |
| 두 번 등록됨 | 같은 분(分)·같은 가맹점·같은 금액이면 자동으로 걸러집니다. 그래도 생기면 알려주세요 |
