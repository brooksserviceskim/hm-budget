# 문자(SMS) → 생활비 자동 반영 설정

카드 승인 문자가 오면 **폰이 자동으로 앱에 지출을 등록**합니다.
웹앱은 문자를 읽을 수 없어서, 폰에 자동화 앱을 하나 깔고 거기서 보내주는 방식입니다.

- 문자 내용은 **폰 안에서만** 처리되고, 서버로는 **금액·가맹점·시각**만 전송됩니다
- 카드번호·잔액 같은 건 보내지 않습니다
- 같은 결제는 두 번 등록되지 않습니다

---

## 0. 먼저 할 일 (PC에서)

Supabase SQL Editor 에서 `supabase/migration-budget-sms.sql` 을 실행하세요.
그리고 아래 SQL로 **비밀키를 본인만 아는 값으로** 바꿉니다.

```sql
update public.settings
set value = '{"secret":"여기에-본인만-아는-문자열"}'::jsonb
where key = 'sms_secret';
```

이 비밀키가 있어야만 문자로 지출을 등록할 수 있습니다. 남에게 알려주지 마세요.

---

## 1. MacroDroid 설치 (갤럭시)

Play 스토어에서 **MacroDroid** 설치 (무료 버전으로 충분합니다).

## 2. 매크로 만들기

**매크로 추가** → 이름 `카드문자 → 가계부`

### 트리거
**+ 트리거 → 기기 이벤트 → SMS 수신**

- 발신자 : `15881688` (삼성카드) — 다른 카드도 쓰면 매크로를 하나 더 만드세요
- 내용 포함 : `승인`

### 조건 (선택)
**+ 조건 → 문자 내용에 `취소` 포함 안 함** — 취소 문자를 거르려면 추가하세요.

### 액션 1 — 금액 뽑기
**+ 액션 → 변수 → 변수 설정**

- 변수명 `amount` (정수)
- 값 : `[sms_message]` 에서 정규식 추출
  ```
  ([0-9,]+)원
  ```
- 추출한 값에서 쉼표 제거 (MacroDroid 의 `문자열 조작 → 바꾸기` 로 `,` → 공백)

### 액션 2 — 가맹점 뽑기
**+ 액션 → 변수 → 변수 설정**

- 변수명 `merchant` (문자열)
- 값 : `[sms_message]` 에서 정규식 추출 — **실제 문자 형식에 맞춰야 합니다**

### 액션 3 — 서버로 전송
**+ 액션 → 연결 → HTTP 요청**

| 항목 | 값 |
|---|---|
| 방식 | POST |
| URL | `https://jjlmmebptyefmrqbrisw.supabase.co/rest/v1/rpc/ingest_sms` |
| Content-Type | `application/json` |

**헤더 추가**

```
apikey: sb_publishable_WUTZ8a4bBrGALf6WLISXBA_vgzAzi4L
```

**본문 (Body)**

```json
{
  "p_secret": "여기에-본인만-아는-문자열",
  "p_amount": [lv=amount],
  "p_merchant": "[lv=merchant]",
  "p_owner": "김현우"
}
```

### 액션 4 — 확인용 알림 (선택)
**+ 액션 → 알림 → 알림 표시** : `가계부 등록 [lv=merchant] [lv=amount]원`

---

## 3. 테스트

1. 매크로 저장 후 **테스트 실행** 을 눌러보거나, 실제로 카드를 한 번 긁어봅니다
2. 앱의 **생활비** 탭을 새로고침하면 방금 결제가 `문자` 태그와 함께 올라와 있습니다
3. 분류가 `미분류`로 뜨면 앱을 열 때 가맹점 이름으로 자동 분류됩니다

---

## 4. 안 될 때

| 증상 | 원인 |
|---|---|
| 아무것도 안 올라옴 | 비밀키 불일치 · apikey 헤더 누락 |
| 금액이 이상함 | 정규식이 누적금액을 잡음 → `승인` 뒤 첫 금액만 잡도록 수정 |
| 가맹점이 비어 있음 | 카드사 문자 형식이 달라서 → 실제 문자 예시를 알려주세요 |

카드사마다 문자 형식이 달라서 **정규식은 실제 문자를 보고 맞춰야 정확합니다.**
받은 승인 문자 한 통을 그대로 알려주시면 정확한 정규식을 만들어 드립니다.
