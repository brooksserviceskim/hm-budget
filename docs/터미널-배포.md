# 터미널로 깃허브에 올리기

압축 → 웹 드래그 대신, 명령 한 줄로 배포합니다.

## 준비 (최초 1회만)

터미널을 열고 순서대로 실행합니다. `Command + Space` → `터미널` 입력 → 엔터.

### 1. git 설치 확인

```bash
git --version
```

버전이 안 나오면 설치 창이 뜹니다. `설치` 눌러 끝날 때까지 기다립니다.

### 2. 깃허브 로그인 (권장)

```bash
brew install gh
gh auth login
```

`GitHub.com` → `HTTPS` → `Y` → `Login with a web browser` 순으로 고르면
브라우저가 열려 로그인됩니다. **터미널에 비밀번호나 토큰을 칠 일이 없습니다.**

`brew` 가 없다면 먼저:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

> gh 없이 써도 됩니다. 대신 첫 푸시 때 git 이 사용자명과
> 비밀번호(= 개인용 액세스 토큰)를 물어보고, 이후 맥 키체인에 저장됩니다.

## 배포하기

```bash
cd ~/Desktop/"수입 지출 관리"/brooks-budget
bash deploy.sh
```

처음 한 번만 깃허브 사용자명과 저장소 이름을 물어봅니다.
입력하면 `.deploy.conf` 에 저장되고 다음부터는 안 묻습니다.

수정 내용을 남기려면 뒤에 붙입니다.

```bash
bash deploy.sh "환율 기능 추가"
```

생략하면 `업데이트 2026-08-29 21:30` 처럼 시각이 들어갑니다.

### 더 짧게 쓰기

```bash
echo 'alias 가계부배포="cd ~/Desktop/\"수입 지출 관리\"/brooks-budget && bash deploy.sh"' >> ~/.zshrc
source ~/.zshrc
```

이후로는 어디서든:

```bash
가계부배포 "필터 기능 추가"
```

### 터미널이 싫다면

폴더 안의 **배포.command** 를 더블클릭하면 터미널이 알아서 열립니다.
처음 한 번은 실행 권한이 필요합니다.

```bash
chmod +x ~/Desktop/"수입 지출 관리"/brooks-budget/배포.command
```

## 스크립트가 하는 일

1. `.git` 이 없으면 저장소를 만들고 원격 주소를 연결
2. `.gitignore` 생성 (`.DS_Store`, `node_modules`, `*.zip` 제외)
3. 바뀐 파일 전부 커밋
4. `main` 브랜치로 푸시
5. 사이트 주소 출력

## 자주 나오는 문제

**`rejected` / `non-fast-forward`**
깃허브에 이미 웹으로 올린 파일이 있을 때입니다.
스크립트가 덮어쓸지 물어봅니다. `yes` 를 입력하면 이 폴더 내용으로 맞춰집니다.
반대로 깃허브 쪽을 살리려면 중단하고:

```bash
git pull --rebase origin main
```

**`Repository not found`**
저장소가 없거나 로그인이 안 된 상태입니다.
https://github.com/new 에서 Public 으로 만들거나 `gh auth login` 을 실행하세요.

**설정을 바꾸고 싶을 때**

```bash
rm .deploy.conf
```

다음 실행 때 다시 물어봅니다.

**화면이 그대로일 때**
깃허브 페이지 반영에 1~2분 걸립니다. 그 뒤에도 그대로면 새로고침하세요.
앱이 캐시를 쓰기 때문에 `sw.js` 의 버전이 올라가야 갱신됩니다.
